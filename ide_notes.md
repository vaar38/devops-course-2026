   # Git в VS Code vs терминал

   ## Удобно в VS Code
   1. Наглядный diff: изменения видны построчно, красным и зелёным.
   2. Граф коммитов показывает ветки и историю визуально.
   3. GitLens показывает автора и дату каждой строки прямо в редакторе.

   ## Удобнее в терминале
   1. Понятные ошибки: терминал сразу показывает, что пошло не так, и подсказывает команду для исправления
