# Git vs SVN

1. **Почему ветвление в Git дешёвое?**
   В Git ветка — просто указатель на коммит, в SVN — копия папки на сервере.

2. **Можно ли в SVN коммитить без интернета?**
   Нет: SVN централизованный, коммит сразу идёт на сервер.

3. **Когда SVN лучше Git?**
   Большие бинарные файлы, блокировка файлов, права на отдельные папки, legacy-проекты.
